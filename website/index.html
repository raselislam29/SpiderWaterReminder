Three moves

Install once. Remind forever. Dismiss with a click or Esc.

1

Install

Grab the Windows installer or the Mac disk image, then open SpiderWaterReminder. The icon sits by the clock on Windows, and in the menu bar on macOS.

2

Set the drop

Type your message, pick At Time or Repeat, then hit Set Reminder.

3

Stay hydrated

When time’s up, the drop covers every screen. Click or press Esc to clear it.

Security warning on first launch?

On Windows, choose More info → Run anyway. On macOS, right-click the app and pick Open. The app is free and unsigned until a code-signing certificate is added.
